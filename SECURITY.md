# Security policy

## Supported version

Security fixes target the latest commit on `main` while AtlasTint is in its initial release cycle.

## Reporting a vulnerability

Do not disclose a suspected vulnerability in a public issue. Use [GitHub private vulnerability reporting](https://github.com/martonpaulo/atlas-tint/security/advisories/new) and include:

- the affected behavior and realistic impact;
- reproducible steps or a minimal proof of concept;
- relevant browser and operating-system details;
- any mitigation already tested.

AtlasTint is local-first and has no backend, account system, or analytics service. Reports concerning browser storage, imported JSON, build or deployment supply chains, and unsafe rendering boundaries are still in scope.
